🎯 **What:** The testing gap addressed
Added missing tests for the `checkAdminAuth` function in `internal/api/handlers.go`. This function checks both the environment configuration (`adminToken`) and the request header (`X-Admin-Token`).

📊 **Coverage:** What scenarios are now tested
1. **Server configuration error:** Checks the behavior when the server's `adminToken` is empty (returns `false`, sets 500 status, and returns a JSON error).
2. **Missing Header:** Checks the behavior when the `X-Admin-Token` header is missing from the request (returns `false`, sets 401 status, and returns a JSON error).
3. **Incorrect Header:** Checks the behavior when the `X-Admin-Token` header is present but incorrect (returns `false`, sets 401 status, and returns a JSON error).
4. **Correct Header:** Checks the behavior when the `X-Admin-Token` header is present and matches the configured token (returns `true` without setting an error status).

✨ **Result:** The improvement in test coverage
The `checkAdminAuth` helper function is now fully tested across all its branching logic, ensuring proper authorization checks are enforced for admin endpoints and preventing regressions if the authentication logic is modified in the future.
