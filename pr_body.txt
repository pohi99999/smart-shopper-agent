💡 **What:**
Updated `APIHandler` to compute and cache the `SHA-256` hash of the `ADMIN_TOKEN` during initialization, replacing the redundant on-the-fly calculation per request with a constant-time comparison against the cached slice.

🎯 **Why:**
The previous implementation performed a redundant `sha256.Sum256([]byte(h.adminToken))` calculation on every incoming GET and POST request to the admin prices endpoints. Caching this value avoids the CPU overhead.

📊 **Measured Improvement:**
Due to HTTP routing and request parsing overhead in `httptest`, full handler benchmarks showed noisy results. An isolated benchmark comparing the core logic demonstrated a ~41% reduction in execution time for this specific path:

**Baseline (Unoptimized):** `609.2 ns/op`
**Optimized:** `358.9 ns/op`
